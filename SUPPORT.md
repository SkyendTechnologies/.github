# Support

Support is handled per repository.

Before asking for help:

1. read the repository README and documentation;
2. search existing issues and discussions;
3. confirm that the problem still occurs on a supported version or current branch;
4. collect a minimal reproduction, relevant logs, and environment details.

For bugs and feature requests, use the repository's GitHub issue forms when available.

For general Skyend Technologies communication:

https://t.me/SkyendTechnologies

For security vulnerabilities, follow [SECURITY.md](./SECURITY.md) instead of opening a public support request.
